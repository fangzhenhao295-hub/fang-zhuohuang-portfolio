Second Chapter / 第二人生

人只能生活一次，影像却使一段生活有了被重新观看的可能。

“‘附近’不是一个有边界的单位。”

项飙

我的许多拍摄，都从一些并不显眼的地方开始：清晨刚开门的市场、村里一年一度的仪式、雨中的训练场、毕业散场后的校园，以及一件产品被摆到灯前的片刻。

这些地方原本各有自己的时间，人们照常劳作、交谈、等待。摄影者到来以后，现实并不会因此停下；能做的只是跟上一段生活，在它经过时看清一点，再把其中值得留下的部分带回来。

我最初接受的是设计训练，后来越来越多地把时间交给影像。摄影因此成了我的“第二人生”：它不是逃开原来的生活，而是在原有身份之外，重新获得一种进入世界的方法。

我跟随非遗仪式穿过村落，也观察食物怎样牵出一座城市的记忆；我记录台湾教练与大陆学生在雨里训练，陪他们走到毕业前的最后一场主场比赛；我也进入品牌、景区、媒体和校园机构，在传播任务与真实生活之间寻找不过度打扰的表达。

“第二人生”也指摄影对现实的第二次书写。现实先发生，镜头随后而来。观看、等待、取景和裁切，看似只是技术动作，实际上都在回答同一个问题：这一段生活应当怎样被别人看见。

拍摄留下的是现场的一部分，剪辑又把这些片段重新放进时间里。影像不是现实的替身，而是一种带着位置、责任和分寸的叙述。

这份作品集沿用摄影和印刷里的取景框、定位线、网格与裁切标记。它们不把作品关进一个封闭的框，而是提示观看从哪里开始、又在哪里留有余地。

照片、人物和项目会不断更换，观看与叙述的规则则保持一致：首页呈现影像实践，团队管理、品牌协作、跨学科项目与荣誉材料收在信息层中，供愿意继续了解的人展开阅读。

CAPABILITY MAP / 能力范围

从地方出发，把目光放得更远。

“从基层上看去，中国社会是乡土性的。”

费孝通

我理解的“在地”，并不是停留在原地。市场里反复响起的冰柜声、村落里一年一度的仪式、城市正在改变的光线，都训练我先辨认人与环境之间真实的关系，再决定镜头站在哪里。

这种观察方法并不把题材锁在乡土。作为年轻创作者，我也向消费电子、城市、汽车与未来生活走去：设计训练帮助我整理形式，影像帮助我组织时间，AI 与数据工具则用于预演、验证和提效。对象不断变化，方法保持连贯：先理解现场，再让技术服务于清楚、可信的叙事。

IMAGE ARCHIVE / 图片档案

把走过的地方，留在照片里。

这里收录的是我在校园、街巷、旅途与拍摄现场持续积累的照片。它们不是视频项目的补充材料，而是另一种更直接的观察。

一张照片只处理一个时刻，却能把人物与环境的关系留得更久。我按照创作场景将它们分为手机摄影、相机摄影、产品摄影与个人创作，你可以从任意一组开始浏览。

SELECTED FILMS / 精选影像

作品从哪里来，便从哪里讲起。

“我关注现实中的人，他们的命运慢慢形成了我的一个表达的愿望。”

贾樟柯

学校、村落、市场、景区和训练场，是作品发生的地点，却不是理解作品最要紧的线索。同一个校园里，既有我主动追踪的人和事，也有需要完成的品牌任务。

因此，这里的作品按我与现场建立关系的方式排列。一类由我发起：先有疑问或感受，再去寻找人物、资料与影像结构，我对选题和叙事承担主要责任。

另一类由合作或委托开始：作品有明确的传播对象与交付目标，我需要理解品牌或机构的需要，也要保护现场原有的质地。两类工作使用相同的摄影与剪辑方法，却要求不同的分寸。

BIOGRAPHY / 个人简介

设计是我学习观看的起点，影像让我真正走进生活。

2005.01.25浙江金华中共党员2027 届本科生班级团支书龙岩市摄影家协会会员

我在泉州师范学院纺织与服装学院学习服装与服饰设计。设计训练让我对构图、色彩、材质和信息秩序保持敏感，影像则把这种敏感带到真实的人和地方之中。

大学期间，我的镜头往返于福建的村落、市场、景区、校园和公共活动现场：有时记录一种手艺怎样被传下去，有时跟随一支队伍经历比赛，也有时要在有限时间里完成一个品牌或机构的传播任务。

乡土、消费电子、城市与未来生活并不是四条突然分开的线。它们都要求我理解人如何使用物、进入空间并赋予经验意义。

面对村落，我先看关系与时间；面对产品，我把同样的耐心放到材质、光线和使用情境里。设计、影像、AI 与数据方法在这里互相补充，让我能从真实现场出发，也能继续向外走。
